# 值观 Zhiguan

> **让时间与金钱，流向真正重要的生活。**

值观（**ZHIGUAN**）是一款面向个人的 **Personal Value Flow（个人价值流）** 产品：它把时间、收入、成本、目标、订阅与物品使用放在同一条可解释的价值链上，帮助人看清每一次选择带来的投入、结果与余量。

> **品牌承诺：不替你定义什么值得，只帮助你看清每一次选择。**

## 当前状态

项目目前处于产品定义与治理初始化阶段。仓库正在建立产品宪法、策略、路线图和数据原则，**目前没有可运行应用、运行时 API、数据库 Schema 或可安装的软件包**。因此现在没有安装或启动命令；后续实现必须先通过产品与架构决策文档。

当前目标用户、功能顺序和实现方式都是可验证假设，不代表已经完成用户验证。

## 核心命题

值观不把人生简化为一张记账表，也不替用户判断什么“最划算”。它关注的是资源如何流动，以及这些流动是否支持用户真正重视的生活：

```text
Capture → Normalize → Understand → Simulate → Decide → Review → Learn
记录       统一口径      理解关系       推演选择       做出决定      复盘       形成个人判断
```

产品会区分事实、用户确认、估算、预测和数据不足，优先提供证据、口径和解释，再把决定权交还给用户。

## 仓库边界

当前仓库只承载产品决策和治理材料，不承载真实收入、资产、订阅或其他个人敏感样例数据。新增能力必须说明它服务的用户任务、处于价值循环的哪一环、使用哪类数据、如何解释结果，以及会增加多少长期输入负担。

文档优先级固定为：

```text
PRODUCT.md > PRODUCT_STRATEGY.md > ROADMAP.md > PRD / RFC > Issue > 实现
```

`ARCHITECTURE.md` 服从产品宪法并约束所有技术工作；批准后的 ADR 在其适用范围内优先于 Issue 和实现，但不能覆盖上位产品文档。

当文档之间出现冲突，应先停止实现，按上述优先级处理并留下决策记录。
