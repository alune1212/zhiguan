# ADR-0008：同浏览器基础资料复用与购买收藏

**状态：** Accepted；Q1–Q13 方案及技术边界已获批准，功能实施中。现有购买工作台仍为内存态；新流程尚未整体交付，迁移、备份往返与回滚尚未完成或验证。与 [RFC-0001](../product/rfc/RFC-0001-income-understanding.md)、[PRD-0003](../product/prd/PRD-0003-income-dashboard.md) 配套生效。

为避免反复填写稳定收入与作息，用户选择在同一设备、同一浏览器保存基础资料，不引入账户与跨设备同步。首次通过“保存并开始”明确触发保存，并告知资料仅存于此浏览器；清除浏览器数据可能造成丢失。购买结果由用户按需收藏，保留当时使用的资料与计算口径，后续修改基础资料不改写收藏，不自动保留全部试算。

相较只导出单次 JSON，本地保存降低再次使用的负担；相较账户同步，它不需要身份和云端保存，但无法承诺换设备恢复。不将保存范围扩展到对话原文或未收藏的草稿。

## 保存、导入与删除

最小实现采用一个带版本的浏览器 localStorage 文档，包含最新基础资料和收藏快照；不持续保存逐秒金额。记录资料更新时间，保留默认来源与证据状态。保存前序列化和校验，写入失败保持原存储并提示本次仅临时使用，不悄悄换存储介质或清空数据。多标签页发现保存基线已变化时提示重新载入，不静默覆盖。

不承诺本地加密、浏览器清理后的恢复或云端副本。设置中提供删除单项收藏、清空全部资料及备份出口；清空前说明影响并确认，不删除用户已下载文件。切回旧版应用不会自动删除新资料，回滚前仍提供备份与清空出口。

备份格式使用 `zhiguan-local-backup@1`，只保存本地资料、收藏及必要版本/时间信息。导入完整验证格式版本、字段类型、金额精度、时区、时段及收藏结构，未知版本或损坏文件不得部分写入或用默认值修复。校验成功并经用户确认覆盖后一次替换；取消或写入失败保留原数据。导入文本始终按数据处理，不执行内容，不发起网络请求。

## 计算与公开格式

新看板及从其进入的新购买草稿默认统一使用选定时区内当月计划工作总秒数，不再静默使用 52 周 / 12 月估算。用户可主动为单次购买比较选择旧的平均作息或直接填写月工时作为覆盖；界面明确显示使用了不同口径，沿用既有校验和精度，仅影响该次草稿，不更新基础资料。金额仍为精确分与有理数，中间结果不提前舍入；作息和日历计划估算保持 estimated。默认作息是显式的可修改估算假设，不扩展为未知金额补值。

新日历口径的单次购买导出使用 `zhiguan-purchase-decision@2`，包含比较月份、时区、原始周作息及特殊日期、当月总工作秒数、计算规则版本、输入证据与精确结果；主动使用单次覆盖时，同时记录所选方式及原始依据，不能只把工时塞进旧版字段并省略口径。收藏保存同一份结果快照及收藏时间，后续不按最新规则重算。

旧 `zhiguan-purchase-decision@1` 文件含义保持原样，不推断月份/时区，不作为资料备份导入；第一版不建设旧单次导出的迁移器。备份外层版本与购买快照版本分别校验，只接受本版已支持的结构。未知版本给出明确提示并保留原资料。

## 替代范围、验证和回滚

本 ADR 已获批准；其替代范围仅限新收入看板与从该看板进入的新购买流程：完成实施后，将替代 ADR-0001 的纯内存限制、ADR-0003 的不持久化/不导入限制，以及 ADR-0002/0005 中旧流程的平均月工时与不预选规则。旧 ADR 的历史记录、现有 @1 数据语义和旧购买流程既有验证结论均保留；新流程实施完成前，当前代码仍按既有行为运行。ADR-0007 的主动发送、最少上下文和服务失败接续边界不变，对话从首页入口移至购买中的可选入口。基础资料、收藏及备份不得整体发送 Jev。

验收包括写入失败不破坏旧值、备份往返、未知版本拒绝、删除取消、多标签冲突、收藏不被新资料重算，以及新购买与看板口径一致。无法验证恢复或证据追溯时不交付持久化功能；回滚不静默删除资料、不改写用户下载文件。当前这些验证均未执行。
