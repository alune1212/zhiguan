## 背景

[ADR-0007](ADR-0007-conversational-input.md) 允许用户主动把当前回答和最少上下文发给本机上的 TypeSafe/Jev，用来识别购买字段。该决定写明：不发送完整收入资料，不让模型给出购买建议。架构约束据此把 ADR-0007 视为当时唯一的模型例外，收入看板、基础资料、备份和收藏不得发送。

RFC-0002 把产品改成购买讨论。人物要依据用户自己的收入、工时和余量说话。负责人决定：收入绝对值可以离开设备，交给模型服务商。条件是用户每次都能看到即将发送的全文并确认，应用不留下内容日志。

本决定扩展 ADR-0007 的例外范围。2026-11-11 负责人同时决定：Jev 不关闭，但收成一句话预填讨论表单，见 [PRD-0004](../product/prd/PRD-0004-purchase-council.md)。解析路径仍然不发送完整事实卡，也不生成购买建议。

## 决定

1. **可以发送的内容。** 一次已确认的购买讨论可以发送：事实卡全文（含月收入、日收入、时收入、工时等价、余量、用户已确认并展示在卡上的价格、频率和持有天数，以及卡上已算出的日成本和单次成本）、购买类别、用户写下的想买的理由、这一位人物自己的设定、本轮指令。第二轮还可以发送本轮里已经通过数字校验的发言，包括该人物自己的和别人的。不发送其他人物的设定。未确认的持有天数建议不发送。应急金和其他存款分开出现在事实卡上，只有用户填写且展示出来的那一项才发送，不合并成一个数。
2. **不发送的内容。** 不发送 API 密钥、其他收藏、整份本地备份、逐秒看板的刷新状态、与这笔购买无关的历史讨论、未启用的人物，以及被数字校验挡下的句子。用户没填的应急金、其他存款、固定支出或余量不补零后发送。未确认的持有天数建议同样不发送。
3. **预览和确认。** 每份新载荷发送前，向用户展示将要发送的全文，包括服务商名称和主机名。用户确认后才发送。拒绝确认时不发请求。一次确认覆盖这一轮的人物请求和随后的综合请求，也覆盖同一份载荷的失败重试。综合不加入新的用户数据，只使用已经预览过的事实卡、类别、理由、人物设定，以及本轮通过校验的发言。预览里要列出综合会收到这些部分里的哪一些。第二轮、改过人物、改过输入或重算过事实卡，都是新载荷，必须重新预览。
4. **应用不记日志。** 服务端不记录请求正文、响应正文、事实卡和提示词，也不把它们写入持久存储。错误可以留下不含正文的失败类别，供用户看到「这次没生成」。若托管平台有关不掉的连接日志，预览里写明平台名称，不把这种日志说成无人可见。
5. **服务商不在本决定里承诺删除。** 与 ADR-0007 相同：对方收到之后如何保留，以对方的说明为准。预览里要有这一句。本地删除和清空不能撤回已发送的请求。
6. **密钥。** 只放在服务端环境变量中，不使用 `VITE_` 前缀，不进仓库、截图和浏览器。浏览器只请求同源接口。密钥缺失时，讨论不可用，事实卡和五种决定仍可用。
7. **服务商。** 阶段一使用 DeepSeek。接口需兼容 OpenAI 风格，并能返回可被结构化校验的结果。密钥能留在我们控制的服务端。预览展示 DeepSeek 的名称和实际主机名。本决定不记录、不比较价格。以后更换服务商，只要仍满足本条和预览规则，不必改宪法。
8. **服务放在哪里。** 新增一个小型 Hono（TypeScript）服务，在服务端保管密钥并转发请求。它替代 `scripts/jev_server.py` 的这一角色，不在 Python 服务上追加讨论或解析接口。服务端不记录请求正文、响应正文、事实卡和提示词，与第 4 条一致。不引入多智能体框架。讨论接口与 Jev 的解析接口分开。解析「想买什么、多少钱、什么类别」时不附带完整事实卡。
9. **本地保存。** 人物设定和讨论记录不写入 `zhiguan-local-backup@1` 的现有字段。实现时使用新的本地格式版本或单独的存储键。旧备份必须仍能导入，导入失败不得覆盖原资料。讨论完成后自动写入本地。用户可以删除单条讨论，也可以全部清除已保存的讨论。这些记录随现有的导出和清空一起进出。还没完成的讨论不落盘。刷新后未完成的内容可以消失，这一点要在界面上说明。

事实卡的字段和引用规则以 [PRD-0004](../product/prd/PRD-0004-purchase-council.md) 为准。本决定不新增一种用户之间交换的公开格式。

## 与 ADR-0007、ADR-0008 的关系

- ADR-0007 的最少上下文、不发送完整收入资料、不生成购买建议继续有效。当前代码仍是多轮填表。讨论功能实现时，Jev 改为 PRD-0004 的一句话预填，由用户确认。实现前，运行中的外发仍只按 ADR-0007。
- 本决定替代的是本 PR 改写架构文档之前的两句原文：「收入看板、基础资料、备份和收藏不得发送给 Jev」，以及「ADR-0007 是当前唯一的 AI 与外部服务例外」。前一句说的是当时的代码行为，讨论功能接入前仍然如此。后一句只描述当时的产品边界。替代只发生在本决定描述的、经过预览确认的讨论载荷上。Jev 的一句话解析仍不发送完整收入资料，不在这条替代范围内。
- ADR-0008 的看板、收藏和 `@1` 备份格式保持原义。本决定第 9 条是在其旁边增加的本地范围，不是把收入资料改成默认同步到云端。
- ADR-0006 仍是被 ADR-0007 替代的历史记录，与本决定无关。

## 回滚

实现后若预览可以被跳过、应用写下了正文日志、密钥进入了浏览器，或讨论接口把完整事实卡转给了 Jev 填表，就停止讨论接口。已保存的本地人物和讨论保留导出与删除。Jev 填表、收入看板和手动购买计算不受这次停止影响。

不实现本决定时，无需迁移数据。
