# ADR-0007：对话优先输入与最少上下文

状态：Accepted；本机实现完成；已核验并带一项非阻断警告归档（2026-09-22）。用户确认七项选择并授权实施，本决定取代 ADR-0006 的首版交互范围；具体结果和限制见[变更验证记录](../../openspec/changes/archive/2026-09-22-conversational-purchase-input/tasks.md)；[归档核验报告](../../openspec/changes/archive/2026-09-22-conversational-purchase-input/verification.md)记录了含糊改口的追问偏差。

与 ADR-0008 的配合范围：Jev 对话只在用户主动进入的购买分析中可用；收入看板、保存资料、收藏和备份不调用 Jev，也不发送其内容。购买单次覆盖的平均作息或直接月工时可按既有识别边界处理，仍保留原证据状态，不改写保存资料。

## 已确认的选择

1. 一句话输入与按需追问作为主入口，手动填写作为随时可切换的次级入口。先完成收入、税口径、购买价格和作息所需的核心结果；用户主动选择查看余量后再追问固定支出及本月付款，已主动提供的相关信息不要求重复输入。
2. 识别结果自动整理成可编辑的待确认摘要，整体确认一次后查看结果，不再要求逐字段确认及返回表单二次确认。歧义单独追问，约数及作息换算保留 estimated。
3. 多轮请求只向 TypeSafe/Jev 发送当前回答、当前问题和理解所需的相关已知字段或原文片段。首次发送前说明处理方，用户主动发送后继续本次会话，不每轮弹窗；页面打开不自动上传，会话仍仅保存在内存中。
4. 明确改口直接更新待确认摘要并突出变化，含义不清才追问。已展示结果时，修改输入使旧结果及导出失效，须重新整体确认；已有决定不能自动绑定到新结果。
5. 每次只问一个关键问题，允许不知道或跳过。同一问题澄清一次仍不明确就停止重复追问，保留 insufficient-data 并提供直接修改入口，不以默认作息或猜测补齐。
6. 自然语言输入与少量快捷按钮并存，已提供的信息不重复询问；点击明确选项直接填写，不为该选择调用 Jev。
7. 识别或服务失败时保留当前会话进度，提供主动重试及手动补充。手动入口沿用已整理信息及待确认状态，不要求重填，不后台反复重试或猜值。

本决定替代 ADR-0006 的单段描述和三字段限制，允许为理解改口和指代发送当前回答、当前问题与必要的最少上下文。首次发送前说明外发范围；页面打开不自动发送，手动输入与快捷按钮不调用 Jev。服务商接收后的数据无法由本地清空撤回，不对其保留政策作新承诺。

## 实施边界与验证

复用现有本机 Python 服务、候选值与原文依据校验、浏览器计算和手动表单。Jev 负责语义识别；代码负责校验、确定下一项必要问题、展示预写追问及计算，不增加自由文本生成模型。金额、作息和余量相关输入服务于当前单次购买任务，价值期待和最终决定仍由用户表达，不让 Jev 推断购买建议。

已将现行策略、路线图、架构、PRD 和相关 ADR 同步到批准范围。继续限定本机使用、CNY 月度口径和内存态；不扩展公开部署、账户、持久化、同步或公开导出格式。对话原文和会话内部状态不进入 JSON 导出。

验证覆盖一句话多字段、作息缺失、歧义与明确改口、约数、跳过、可选余量、快捷按钮不发请求、失败后手动接续及旧决定不随新输入导出。以虚构中文样本验证 Jev，区分服务成功、字段正确和实际交互负担；原有三字段样本结果不能证明新增能力可用。检查从首次输入到核心结果的输入与确认次数，并完成相关 Bun 检查及键盘、窄屏验证，不将尚未测量的速度或准确率写成收益。

发现无依据填值或歧义强行确定时暂停该能力交付，修正并验证；服务不可用时可切换手动流程。停止本机辅助服务即可关闭 Jev 能力，当前会话的手动流程仍可继续。

本 ADR 只批准以上单次购买对话输入范围；不批准公开部署、持久化、同步或其他外部服务。真实模型小样本、输入操作次数和键盘/窄屏检查已分别记录；不将小样本结果表述为一般准确率或全面可访问性认证。
