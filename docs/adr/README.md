## 什么时候需要 ADR

只有新增持久化、身份、同步、外部服务、敏感数据处理，或改变公开导出/计算格式时，才先写 ADR。ADR 应说明背景、决定、影响和回滚触发条件。

已实现的 ADR 不删除；决定失效时标记为 Superseded 或 Deprecated，并留下替代路径。
