# ADR-0003：当前工作流的一次性 JSON 导出

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted；取代本 ADR 在 2026-08-24 记录的双格式原型合同 |
| 日期 | 2026-09-01 |
| 范围 | 单次购买决策工作台与数字型 Goal 进度 |

## 背景

旧原型为 JSON、Markdown、预览、修订历史、构建清单和兼容校验建立了完整合同。当前产品没有导入器、持久化历史或需要消费这些格式的外部接口，这套机制增加了维护成本，却没有推进用户的购买决策任务。

## 决定

- 购买决策和 Goal 各自只保留用户主动触发的一次性 JSON 下载；不保留 Markdown、预览层、导入、修订历史、构建清单或兼容框架。
- 只有用户提交对应工作流的当前输入后才允许导出；输入随后改变时必须重新计算。
- 购买文件包含当前输入及证据状态、五个当前结果及不足原因、用户决定、依据和复盘条件。
- Goal 文件包含目标名称、目标值、当前值、用户单位、两项证据状态、完成比例、剩余差距和不足原因；不包含购买工作台数据。
- 金额、目标和比例的精确值继续使用字符串分子/分母表达，不使用会丢失精度的 JSON number。
- 页面只在内存中创建 `Blob` 和临时 object URL，不上传、不持久化，也不声称浏览器已成功保存文件。
- `format` 字段分别标识购买决策和 Goal 结构；没有导入器或已知消费者时不维护旧原型兼容层。

## 结果

导出仍满足用户主动带走当前数据的需要，同时让两个工作流保持独立，并继续删除未被产品使用的双格式和版本治理。将来只有在出现真实外部消费者、导入需求或持久化历史时，才定义新版本、迁移和兼容策略。
