# ADR-0001：本地浏览器内存态 React/Vite

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-21 |
| 范围 | 单次购买决策工作台 |

## 背景

当前目标是尽快验证一个单次购买决策流程。账户、服务端、数据库和同步会增加部署、隐私与维护成本，却不是这个流程的必要条件。

## 决定

- 使用 React、TypeScript 和 Vite 构建单页应用。
- 会话数据和计算结果只放在浏览器内存；刷新、关闭或退出后不恢复。
- 不引入运行时 API、数据库、账户、云端同步、Cookie、Web Storage、IndexedDB、分析或第三方网络资源。
- 使用浏览器原生能力完成输入、展示、可访问交互和用户主动的本地文件导出。

## 结果

本地开发和静态预览足以交付当前功能，用户数据不经过应用服务器。下载文件离开应用控制后由用户设备负责。需要持久化、身份、网络服务、同步或第三方处理时，必须先重新评估本决定。

## 实施更新

2026-09-03，依赖管理和开发工具运行时统一为 Bun，继续使用 React、TypeScript、Vite 和 Vitest。应用仍以浏览器单页交付；工具版本、安装和验证方式见根目录 `package.json`、`bunfig.toml` 与 `README.md`。

## 不在本决定内

研究招募、研究记录、托管服务、账户系统、后台任务、提醒和 AI 均不是当前实现。
