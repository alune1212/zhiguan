# ADR-0006：Jev 首版接入边界

状态：Superseded by ADR-0007（2026-09-22）。本记录保留首版三字段辅助填写决定和虚构样本实验；不再定义当前交互范围。

## 首版接入决定（历史，曾生效）

2026-09-21 用户批准在既有表单增加三字段辅助填写入口，整理月收入、税前/税后口径和购买价格。描述由用户主动提交到本机 Python 服务，再发送给 TypeSafe/Jev；该首版请求不发送其余表单内容。候选值、原文依据和不足状态展示后，由用户编辑并确认；首版只填空白字段，不覆盖已有值。金额与税口径独立判断；约数保持 estimated。计算仍在浏览器执行，服务失败不阻断手动流程。2026-09-22 起，该范围由 ADR-0007 的对话优先输入决定替代。

密钥仅由服务端 `.env` 加载；无描述正文日志、无数据库或浏览器持久化。应用清空时取消请求、清除描述和候选；已发往服务商的请求无法撤回，不承诺其保留政策。当前仅绑定回环地址用于本机运行；公开部署与多人服务不在本次范围。保留原 JSON 格式，描述不导出，确认后的字段沿用现有证据状态。可停止 Python 服务撤回辅助能力，手动表单继续可用。

先以新增虚构样本验证字段独立性、歧义和估算，再接入页面。新增样本若出现无依据填值或歧义强行确定，暂停页面接入并报告。置信度不是事实或授权。

## 实验阶段事实（历史）

- 用户要求安装 TypeSafe Python SDK，并讨论 Jev 如何融入当前购买工作台。
- 已添加最小 Python 依赖清单，安装 `typesafe-sdk==0.7.0`；SDK 导入通过。方案确认后已完成 20 次虚构样本远程调用，详见[首轮结果](../jev-experiment-results.md)。
- 安装 SDK 时产品以 React/Bun 和浏览器内存态运行，策略与架构规定不联网、暂不接入 AI；这些限制已按顶部用户批准范围作有限调整。
- Jev 处理文本并返回类型化判断与概率，不生成自由文本解释；类型正确不代表判断正确。

## 实验阶段方向（历史）

验证“从一句购买描述整理待确认输入”：代码提取原文候选数字，Jev 判断各候选对应收入、价格或其他字段。没有候选或含义不明时保留空缺，不自动填零或猜测。实验只输出供核对的结果，不进入产品计算流程。

本轮不开展价值期待的澄清问题实验，不判断购买是否值得。

## 首轮实验决策（历史）

1. 范围：先用虚构中文样本做开发实验，再决定是否接入产品；当前不推进产品联网能力。
2. 首要任务：减少数字输入，从一句购买描述整理待确认字段，用户逐项核对后使用现有计算逻辑。
3. 字段范围：月收入、税前/税后口径、购买价格；作息和固定支出不进入本轮。
4. 验证方式：20 条虚构中文样本，覆盖明确表述、缺失、多金额、约数、否定与改口；逐字段核对，记录误填和漏填。出现无依据填值或把歧义直接确定，就不进入产品接入阶段；通过本轮也不自动批准产品接入。
5. 实验形式：手动运行 Python 命令行脚本，输出候选字段、对应原文和待确认项；先验证理解准确性，再决定前端交互。

## 实验调用边界

只发送虚构样本文本及字段判断问题；每条样本一次请求，三个字段一同判断，最多 20 次推理请求，关闭自动重试。模型错误与服务失败分别记录，不以失败结果补零。模型输出均为待确认输入，约数保留 estimated 含义，置信度不替代用户确认。密钥通过 TYPESAFE_API_KEY 环境变量提供，不写入仓库或结果文件。

实验阶段未建立后端或发送用户数据。之后实施的首版接入采用本 ADR 上述历史决定；当前对话请求的授权、上下文和失败边界以 ADR-0007 为准。模型判断始终不是用户决定。

## 运行方式

项目根目录 `.env` 设置 `TYPESAFE_API_KEY`，文件已被 Git 忽略。仅运行命令行实验时加载，不交给前端。

```sh
uv run --locked scripts/jev_experiment.py --self-check
uv run --locked --env-file .env scripts/jev_experiment.py --run --output tmp/jev-results.jsonl
```

第二条命令会产生真实 API 请求。输出文件须不存在，避免覆盖旧记录；每次手动重跑都会产生新请求。脚本默认采用首轮 20 条虚构样本；通过 `--cases` 选择新增样本文件，每批限 1–20 条，请勿写入个人财务文本。结果包含预期、候选字段、原文位置、置信度、模型返回和请求标识；完整匹配与服务成功分别判断。该实验脚本只检查数字原文；产品服务另外通过确定性代码换算候选金额，不能安全换算时留空。

首轮 19/20 条完整匹配，59/60 个字段匹配；一次明确收入金额漏填，无依据填值和歧义强行确定均为零。没有自动重试或针对失败样本重跑。此结果本身不构成接入批准；随后用户另行批准顶部描述的可选接入范围。
