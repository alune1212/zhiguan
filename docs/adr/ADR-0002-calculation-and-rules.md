# ADR-0002：CNY 精确分与证据状态降级

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-21 |
| 范围 | 单次购买决策工作台的金额、时间和余量结果 |

## 背景

购买价格、收入和余量必须可复算；浮点数、隐式换算或缺失值填补会制造看似精确的错误结论。

## 决定

- CNY 金额以整数分表示并使用 BigInt 计算；中间除法保留精确有理数，展示时再按固定规则舍入。
- 计算使用同一比较周期、税口径和解析后的工作时间；工作时间可以来自用户主动选择的作息估算，但不自动换汇、跨期或填充默认作息。
- 作息估算是本决定的显式例外：按每周天数 × 每天小时 × 52 ÷ 12 换算月工时，复用精确有理数处理，并在进入现有月度计算前一次性以 half-up 归一化到小数点后三位；直接填写月工时仍保留原有精度。
- 每个结果保留来源、依赖、公式和证据状态。当前直接填写输入只有 user-confirmed 和 estimated，不声明为 actual；作息换算工时始终为 estimated；可计算的未来结果使用 forecast，无法计算时使用 insufficient-data。
- 缺少、冲突或无效输入时，只让受影响结果降级为 insufficient-data，并给出修正路径；不显示零值、旧值或猜测。当前会话未采集有效日期或历史记录，不自动判断输入是否过期。
- 未来购买情景保持 forecast；近似输入不会被提升为事实。

## 当前计算与导出的五个结果

1. `income-rate`：每小时收入。
2. `work-time-equivalent`：这笔钱相当于多少工作时间。
3. `available-margin`：本月可用金额。
4. `purchase-after-margin`：买完后本月还剩。
5. `purchase-impact`：这笔购买减少的余量。

页面先展示工作时间结论，再补充每小时收入；工作时间可由不预选的快捷作息、自定义作息或次级的直接月工时入口提供，作息换算结果仍以小时展示并保持 estimated。开始补充余量信息后显示两项余量结果；作息估算不改变不依赖工时的余量状态。购买影响只保留在导出中。每项结果的具体依赖见 `src/domain/calculation.ts`，当前页面文案见 `docs/design/purchase-page-copy.md`（均相对仓库根目录）。

## 结果

同一输入会得到确定、可解释的结果；用户能看到口径和不足原因。作息估算明确是近似值，且每日平均小时包含经常性加班、不含通勤与休息，不逐月调整节假日、请假或临时加班。改变金额单位、舍入、状态语义或跨周期规则属于新的架构决定。
