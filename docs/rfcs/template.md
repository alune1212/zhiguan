## 8. 评审记录与决议

RFC 必须按 `Draft → Review → Accepted / Rejected → Implemented → Reviewed` 流转。`Accepted` 只代表提案获批，不代表已经实现；只有同步工作完成并有证据时才能标为 `Implemented`，到期复审完成后才能标为 `Reviewed`。

| 日期 | 评审人 | 意见/条件 | 处理 | 结果 |

| <!-- YYYY-MM-DD --> | <!-- 姓名/角色 --> | <!-- 结论或阻塞点 --> | <!-- 修改/回复链接 --> | 支持 / 有条件支持 / 反对 |

评审人的“结果”是意见，不是 RFC 正式状态。正式状态只在文档信息中使用规定的六种状态。
