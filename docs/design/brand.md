# 值观品牌指南

**版本：** 0.1.1
**更新日期：** 2026-09-03

本指南固定品牌的核心识别与表达边界。视觉系统可以迭代，但不得在没有 RFC 的情况下改变品牌名称、类别、主 Slogan 或品牌承诺。

## 1. 品牌识别

| 层级 | 固定写法 | 说明 |
| --- | --- | --- |
| 中文品牌名 | **值观** | 表达“价值的观察”与用户自己的价值观，不等于替用户下判断。 |
| 英文/罗马字 | **ZHIGUAN** | 全大写用于品牌标识、域名或技术上下文；正文可写 Zhiguan。 |
| 产品类别 | **Personal Value Flow** | 中文为“个人价值流”；它是类别描述，不是第二个品牌名。 |
| 主 Slogan | **让时间与金钱，流向真正重要的生活。** | 长期品牌主句，标点和“真正重要的生活”保持一致。 |
| 品牌承诺 | **不替你定义什么值得，只帮助你看清每一次选择。** | 解释产品态度与用户关系，不改写为“帮你做出正确选择”。 |
| 产品主线 | **看见投入，理解回报；推演选择，保留余量。** | 用于内部产品判断和阶段性内容，不替代主 Slogan。 |

标准组合：

```text
值观
ZHIGUAN
Personal Value Flow
让时间与金钱，流向真正重要的生活。
```

## 2. 核心理念

值观帮助用户看见时间、金钱、拥有和注意力如何流动，以及这些投入是否支持自己真正重视的生活。产品提供可追溯的证据、口径和情景，不把人的生活压缩成单一分数，也不替用户定义什么值得。

三个表达关键词：

- **看见（See）**：把抽象投入和结果变成可理解的关系。
- **理解（Understand）**：说明来源、口径、假设与限制。
- **选择（Choose）**：把判断权交还给用户，允许选择、暂停或不决定。

## 3. 品牌价值观

### 清楚，但不伪装确定

所有结果都应让人知道它是什么、怎么算、从哪里来、还缺什么。动态、预测和 AI 不能以视觉或措辞伪装成事实。

### 尊重个人定义的价值

价格、时间和使用频率是视角，不是人生价值的完整答案。休息、关系、体验和意义可以重要，即使不能被公式完整表达。

### 长期有用，而不是即时刺激

实时数字可以吸引注意，但品牌最终要帮助用户完成理解、推演、决定和复盘。避免 streak、惩罚、羞耻和焦虑式增长。

### 私人、可控、可带走

用户的数据属于用户的生活脉络。默认少收集、少连接、可导出、可删除、可撤回；不要把隐私换成便利的前提当作理所当然。

## 4. 语气与文案

### 推荐语气

- 平静、具体、诚实、有余地。
- 解释口径和不确定性，而不是制造权威感。
- 使用“可以看见”“可能影响”“按当前口径”这类支持判断的表达。
- 面对数据不足时直说“目前无法判断”，并指出需要什么信息。

### 避免语气

- “你应该”“必须买”“浪费了”“不努力就会落后”。
- 把收入、净积累或使用率当成人的成绩。
- “精准预测”“保证回本”“AI 替你做决定”等无证据承诺。
- 以排行榜、等级、连续打卡或损失恐惧驱动使用。

### 文案示例

| 场景 | 推荐表达 | 避免表达 |
| --- | --- | --- |
| 估算 | “按当前口径估算，结果可能受工作时长变化影响。” | “你真正赚到的就是这个数。” |
| 预测 | “这是一个可调整的未来情景，不是承诺。” | “你将在某日完成目标。” |
| 数据不足 | “缺少周期或工作时间，暂时无法安全换算。” | “系统默认按平均值计算。” |
| 购买推演 | “这项选择可能占用相应的工作时间，并改变目标余量。” | “这不值得买。” |
| 复盘 | “你可以记录这次使用是否符合自己的期待。” | “你的购买利用率不达标。” |

## 5. 视觉方向

视觉应让证据、时间关系和用户的呼吸空间优先于装饰。推荐方向是安静、清晰、温和、有层次：

- 以留白、清晰的数字层级和可读的注释承载信息。
- 用稳定、克制的颜色表达状态；颜色不能成为唯一的证据状态提示。
- 动效服务于时间流、变化和因果理解，提供暂停、降低动态或关闭选项。
- 使用图表、时间线和比较卡片解释关系，避免赌场式滚动、闪烁和庆祝粒子。
- 视觉语言兼顾财务信息与生活语境，不默认使用财富、交易、竞争和“暴富”符号。

具体字体、色彩 Token、图标和组件随页面实现演进，并继承本指南的可访问性、隐私和反焦虑要求。是否需要 ADR 遵循仓库根目录 `AGENTS.md`，普通样式调整不要求另建 ADR。

## 6. 命名与扩展规则

- 新功能名优先描述用户能理解的关系或任务，如“购买推演”“目标复盘”，避免夸大收益的营销词。
- 功能可以拥有独立短标题，但必须能回到值观的 Personal Value Flow 类别和价值循环。
- `ZHIGUAN` 是品牌罗马字，不要把 `ValueFlow`、`Value Stream` 或 `Personal Finance` 当作品牌替代名。
- 未来若改变主 Slogan、类别或核心承诺，必须在 RFC 中说明用户影响、迁移文案和历史版本。
