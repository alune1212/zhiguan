# 前端手工验收记录

**记录日期：** 2026-09-23。**环境：** Vite 构建产物的本机 preview 与临时 Docker 容器，均通过 `http://127.0.0.1:4173/` 在浏览器检查。只在隔离测试标签页和该地址的测试存储中使用合成资料。

## 可重复检查

启动当前构建：

```sh
bun run build
bun run preview
```

1. 首次使用先提交无效金额，确认阻止继续并保留字段；再输入有效合成金额并保存。分别查看工作时段、休息时段、有效零值和数据不足，确认状态说明各自正确。〔OpenSpec 3.2〕
2. 从看板打开设置，确认焦点到达设置区域；编辑后取消，检查资料未变；再次编辑并保存，确认新值生效。购买页先用一句话输入，再切换手动填写，检查两者共用草稿；完成一次合成购买并收藏。〔OpenSpec 2.5、3.2〕
3. 对恢复与清空分别测试取消和确认。打开同一资料的两个标签页：在一个标签页保留编辑或确认，在另一个标签页更新资料，再回到旧标签页确认；旧确认应被拒绝且草稿保留。删除唯一的合成收藏，确认出现空状态。〔OpenSpec 2.5、3.2〕
4. 在可丢弃的合成资料上，把本地资料改为损坏内容并重载，再从有效备份恢复。另模拟 `localStorage.getItem` 失败，确认界面显示临时使用提示；模拟 `setItem` 失败，确认原资料未变、未保存编辑仍在。结束后刷新以清除故障注入，并核对存储恢复为测试前内容。〔OpenSpec 2.5、3.2〕
5. 在 320、375、414、768、1280px 宽度检查横向溢出；使用长金额 `999999999999.99` 和长中文重复检查。384 CSS px 下检查了相当于 200% CSS 重排的布局。检查设置焦点、控制台无 error/warn；模拟减少动态偏好后，按钮的动画和过渡时长均为 `0s`。〔OpenSpec 3.3〕
6. 用当前源码构建 Docker 镜像，在临时容器的静态服务打开页面，核对 HTML、JS、CSS 均为 200，且携带原 CSP 与安全响应头；实际操作设置折叠、Radix 选择菜单的 Escape 关闭、保存确认的默认取消焦点及取消后保留编辑。检查样式加载和控制台，最后移除临时容器。〔OpenSpec 1.3、3.3〕

CDP `Network.requestWillBeSent` 观察到：从看板进入购买页、再切换到手动填写，且尚未按发送前，请求数为零。这只证明上述未发送路径；不覆盖用户主动发送后的 Jev 请求。

## 结果与边界

- **2.5：** 已观察五类确认的影响文案和默认取消焦点；设置保存、恢复与清空的取消及确认、删除最后一项、跨标签陈旧确认被拒绝且草稿保留，以及写入失败时原资料与草稿保留。代码中的操作代际与领域 Web Locks 修订号检查另覆盖异步失效路径。未穷举所有并发组合；OpenSpec 任务状态见 [`tasks.md`](../../openspec/changes/redesign-frontend-with-shadcn/tasks.md)。
- **3.2：** 上述合成数据主路径、资料损坏后从有效备份恢复、存储读取失败提示和删除最后一项收藏均已观察。没有进行真实用户财务资料验证。
- **3.3：** 所列宽度均无横向溢出。前景/背景取样对比度为 15.46:1，主色/背景为 5.11:1；这不是所有颜色组合的完整对比度审计。200% CSS 重排已在 384 CSS px 检查，原生浏览器缩放未验证。减少动态模式下按钮无动画或过渡。
- preview 和临时 Docker 容器的浏览器控制台均无 error/warn。Docker 静态服务返回的 CSP 保持为 `default-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`，资源和核心控件操作通过。容器已删除，未更改现有 compose 服务。最终 `bun run check` 通过：依赖检查、类型检查、84 项测试和构建全部通过；`openspec validate redesign-frontend-with-shadcn --strict` 与 `git diff --check` 通过，最终源码已重新构建 Docker 镜像。
