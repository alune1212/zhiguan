# 单次购买页面文案基线

**状态：** 已确认并实施

**版本：** 0.1.1

**更新日期：** 2026-09-03

**适用范围：** `PRD-0001` 单次购买决策页

本文件记录当前页面的文案和信息层级。按结果正负、输入状态切换句子属于界面呈现，不改变输入项、计算规则、状态含义、决定代码或导出格式。

## 1. 表达原则

- 像一个冷静、可靠的人说话，直接把事实讲清楚。
- 先回答用户的问题，再解释数字从哪里来。
- 不要求用户理解“工作时间等价”“预测”“数据不足”等产品术语。
- 不替用户判断买不买，也不评价收入、支出或决定。
- 大概数、未来情况和缺失信息直接写进句子，不只靠标签或颜色表达。

文中的 `{变量}` 代表页面根据本次输入和计算结果替换的内容，不会原样显示给用户。

| 位置 | 文案 |
| --- | --- |
| 品牌 | 值观 |
| 清空按钮 | 清空重填 |
| 页面眉题 | 不显示。主标题已经说明当前任务。 |
| 主标题 | 这次购买要花多少工作时间？ |
| 主标题说明 | 先填月收入、每月工作时间和购买价格，看看它相当于多少工作时间。想算买完后这个月还剩多少，再补每月固定支出。 |
| 页面底部隐私说明 | 你填写的内容只在当前页面使用。刷新或关闭后会清空，不会上传，也不会保存在浏览器里。 |

### 3.3 输入错误

错误紧跟对应输入项显示。页面不使用“参数错误”“数据异常”等笼统说法。

| 情况 | 文案 |
| --- | --- |
| 未选择收入口径 | 选一下月收入是税前还是税后。 |
| 月收入为空 | 填一下每月收入。 |
| 工作时间为空 | 填一下每月工作时间。 |
| 购买金额为空 | 填一下购买价格。 |
| 固定支出为空 | 填一下每月固定支出；没有可以填 0。 |
| 金额格式错误 | 只填数字，不要加逗号或“元”。 |
| 工作时间格式错误 | 只填数字，例如 160 或 160.5。 |
| 金额位数超限 | 这个金额超出可填写范围，请检查；小数最多两位。 |
| 工作时间位数超限 | 这个时间超出可填写范围，请检查；小数最多三位。 |
| 月收入为 0 | 每月收入需要大于 0。 |
| 工作时间为 0 | 每月工作时间需要大于 0。 |
| 购买金额为 0 | 购买价格需要大于 0。 |
| 未确认是否有大概数 | 请确认这些数字里有没有大概数。 |
| 未确认固定支出是否填全 | 请确认你填的是本月全部固定支出。 |
| 未确认购买月份 | 请确认是否按本月付款来算。 |

点击“确认并查看结果”表示用户确认本次输入。勾选“这些数字里有大概数”且至少一项可见结果可计算时，结果区显示大概值说明。当前界面不会产生未选择证据状态，`evidence-required` 只作为数据层兼容状态保留。

## 4. 结果阶段

### 4.1 区块标题

**结果**

不再单独显示“数字和状态说明”。状态含义写进各项结果的正文。

### 4.2 主要结果：工作时间

**结论**

> 按这些数字，这笔钱相当于你工作 {工作时间} 小时的收入。

**展开入口**

> 怎么算出来的

**展开说明**

> 先用月收入除以每月工作时间，算出每小时收入；再用购买价格除以每小时收入。{收入口径说明}

### 4.3 补充结果：每小时收入

**结论**

> 按你填的月收入和工作时间，每小时收入约为 {每小时收入} 元。

**展开入口**

> 怎么算出来的

**展开说明**

> 月收入除以每月工作时间。{收入口径说明}

两项基本结果共用以下收入口径说明：

| 收入口径 | 文案 |
| --- | --- |
| 税后 | 月收入按你选择的税后（到手）金额计算。 |
| 税前 | 月收入按你选择的税前金额计算。 |
| 未选择 | 还需要选择这个收入是税前还是到手。 |

### 4.4 可选结果：扣掉固定支出后

根据结果的正负，只显示对应的一句。

| 情况 | 结论 |
| --- | --- |
| 大于 0 | 扣掉固定支出后，本月还剩 {本月可用金额} 元。 |
| 等于 0 | 扣掉固定支出后，本月刚好没有余量。 |
| 小于 0 | 扣掉固定支出后，本月还差 {本月差额} 元。 |

**展开入口**

> 怎么算出来的

**展开说明**

> 税后月收入减去每月固定支出。

### 4.5 可选结果：买完以后

根据结果的正负，只显示对应的一句。句首的“如果”表明这是按当前条件推算的情况，不再另加“假设结果”标签。

| 情况 | 结论 |
| --- | --- |
| 大于 0 | 如果把这笔购买算进本月，买完后还剩 {买完后金额} 元。 |
| 等于 0 | 如果把这笔购买算进本月，买完后本月刚好没有余量。 |
| 小于 0 | 如果把这笔购买算进本月，买完后还差 {买完后差额} 元。 |

**展开入口**

> 怎么算出来的

**展开说明**

> 税后月收入减去每月固定支出，再减去这笔购买的价格。

### 4.6 结果区统一说明

至少一项可见结果可计算时，按本次输入状态显示下面两句中的一句；全部不可用时不显示这两句：

| 情况 | 文案 |
| --- | --- |
| 数字均已确认 | 按你刚刚确认的数字计算。 |
| 其中有大概数 | 你填了大概数，所以这些结果也都是大概值。 |

结果区始终显示一次计算边界：

> 这里只根据你这次填写的数字计算，不是完整账本，也不会替你决定要不要买。

`{工作时间}` 和金额变量只填入数字，单位由句子提供。`{本月差额}` 和 `{买完后差额}` 使用负数结果的绝对值，让页面显示“还差 300 元”而不是“还差 -300 元”；底层精确值和导出值仍保留负号。

数据层中的“这笔购买减少的余量”继续保留在导出内容里，当前页面不展示，因此不新增一项结果文案。

## 5. 缺失数据阶段

### 5.1 基本结果暂时算不了

输入项旁继续显示第 3.3 节中的具体错误。结果区根据问题类型显示一句，不重复罗列所有错误。

| 情况 | 结果区文案 |
| --- | --- |
| 仍有内容没填 | 还缺{字段列表}，所以现在算不了{结果名称}。 |
| 有内容格式不对、为 0 或超出范围 | 先改正{字段列表}，才能计算{结果名称}。 |
| 两种情况同时存在 | 上面标出的内容还没填好，所以现在算不了{结果名称}。 |

`{字段列表}` 只列出该结果依赖的错误字段，使用“每月收入”“每月工作时间”“购买价格”“每月固定支出”“税前或到手的选择”等用户可读名称，不显示代码字段名。`{结果名称}` 在两项基本结果中分别为“买它要花多少工作时间”和“每小时收入”。

### 5.2 本月剩余金额暂时算不了

确认后，当前固定支出字段非空，或固定支出完整确认、本月付款确认任一有值时，显示相关结果与提示。单独填写“你希望它带来什么”不会触发这些结果。

| 情况 | 文案 |
| --- | --- |
| 收入选择了税前金额 | 你填的是税前收入，所以现在算不了本月剩余金额。请重新填入税后（到手）收入，并选择“税后（到手）”，再查看结果。 |
| 仅缺少固定支出数字 | 还缺每月固定支出，所以现在算不了本月剩余金额。没有固定支出可以填 0。 |
| 未确认固定支出已经填全 | 还需要确认固定支出已经填全，才能计算本月剩余金额。 |
| 未确认购买算进本月 | 还需要确认这笔购买算进本月，才能计算买完后还剩多少。 |
| 固定支出完整性和购买月份都未确认 | 还需要确认固定支出已经填全，并确认是否按本月付款来算，才能计算买完后还剩多少。 |

税前收入提示优先；否则先处理缺失或无效的数字、收入口径，再提示覆盖范围或购买月份确认。数字与收入口径问题沿用第 5.1 节的三个句式，`{结果名称}` 分别为“本月剩余金额”或“买完后还剩多少”。例如仅固定支出有误时，购买前结果显示“先改正每月固定支出，才能计算本月剩余金额。”

缺失时不显示 `0`、旧结果或推测值，也不单独显示“数据不足”标签。

数据层兼容的 `partial`、`unknown` 和 `excluded` 状态不由当前界面产生，因此本页不新增对应选项。无法归入上述原因的不可用结果使用“上面的信息还没填好，所以现在算不了{结果名称}。”

## 6. 决定阶段

| 元素 | 文案 |
| --- | --- |
| 区块标题 | 你准备怎么做？ |
| 选项 `buy` | 现在买 |
| 选项 `wait` | 再等等 |
| 选项 `adjust-conditions` | 换个条件再看 |
| 选项 `do-not-buy` | 这次不买 |
| 选项 `undecided` | 还没想好 |
| 原因标签 | 想记下原因吗？（可选） |
| 原因说明 | 这段话不参与计算。 |
| 下载按钮 | 下载这次记录 |

“再等等”表示已经决定推迟，“还没想好”表示暂时没有决定。页面不推荐任何一个选项。

导出中的 `review_condition` 继续作为兼容字段保留；当前页面没有对应输入项，因此不新增文案。

## 7. 当前界面层级

页面按下面的顺序组织：

1. 主标题和一句说明。
2. 三个基本数字和收入口径。
3. 可选的本月剩余金额输入。
4. 工作时间结论作为主要结果。
5. 每小时收入和本月剩余金额作为补充结果。
6. 计算方式和统一限制说明。
7. 用户自己的决定与下载。

正式状态、计算公式和导出字段继续保留在数据层。页面只把它们翻译成用户能直接理解的句子。
