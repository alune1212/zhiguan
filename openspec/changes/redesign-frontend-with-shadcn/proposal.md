# Proposal

## Why

当前页面仍使用原有 CSS 与容器层级，尚未落实用户选定的 Apple 风格和 shadcn/ui。此次将已确认的 [DESIGN.md](../../../DESIGN.md) 与[页面方案](../../../docs/design/frontend-page-plan.md)落到现有功能上，使手机上短时查看收入估算更清楚，首次填写、设置、购买与收藏保持一致体验。

## What Changes

- 使用浅灰与白色表面、系统字体和统一的 shadcn/ui 控件；收入首页主金额居中，说明与表单左对齐，手机优先并完整适配桌面。
- 顶栏提供收藏与设置，主数字下提供计算依据与购买入口；设置定位并展开首页内的编辑区域，不新增独立路由或侧栏。
- 收藏入口在零收藏时也可达，呈现用途说明、购买入口和返回路径；列表明确展示收藏当时的结果。
- 购买页由目前的「直接填写价格、按需展开对话」调整为「一句话输入优先、随时手动切换」。这是已确认页面方案带来的入口顺序变更，需显式替换现有规格中的对应场景；进入页面、切换入口均不自动调用 Jev。
- 统一首次使用、展开设置、购买结果、收藏及数据不足、未保存、冲突和损坏状态的视觉与可访问性。金额含义、证据等级、计算规则、数据格式与保存范围保持现行契约。
- 实施从手机与桌面概念稿开始，再接入组件和迁移现有页面；概念稿和文档完成均不代表运行界面或用户验收完成。

## Capabilities

### New Capabilities

无。复用现有三项能力，不另建平行的 UI 或视觉系统能力。

### Modified Capabilities

- `income-dashboard`：明确主金额与辅助信息层级、首页操作位置、展开设置的到达路径，以及手机和桌面上的可访问展示。
- `local-profile-and-favorites`：增加零收藏时仍可达的收藏入口、空状态与返回路径，保留当前快照和本地资料规则。
- `purchase-decision-workbench`：将购买输入的默认呈现顺序调整为一句话优先，保留可直接使用的手动输入、同一草稿和主动发送边界。

## Impact

- 页面：`src/app/IncomeApp.tsx`、`src/app/App.tsx`、`src/app/AssistInput.tsx` 与 `src/styles/app.css`；按需增加 shadcn/ui 源码组件。
- 工具与依赖：Bun 接入 Tailwind CSS v4、shadcn/ui 的 Radix 组件及 Lucide；相应调整 Vite、TypeScript alias、`components.json` 和锁文件。保留现有代理、CSP、服务与容器运行约束。
- 验证：更新依赖旧结构或购买默认入口的界面测试，保留领域与本地资料回归；补充导航、空收藏、键盘、窄屏和真实浏览器交互验收。
- 文档：按最终实现同步页面文案与设计状态。此次只创建规划产物；不新增账户、同步、外部服务、持久化范围或公开格式，不需要新的 ADR。
