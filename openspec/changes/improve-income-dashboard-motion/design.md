# Design

## Context

见 `proposal.md` 的动机与 `specs/income-dashboard/spec.md` 的行为契约。当前 `IncomeApp.tsx` 每秒以新的 `Date` 调用 `calculateIncome`，今日与本月金额分别是领域层提供的两位小数字符串；今日主金额由 `currencyDisplay` 整串替换，每秒速率在下方辅助指标。本月分摊、证据状态和本地保存已有独立边界。现有全局 CSS 可关闭 CSS 动画，但不足以保证数字组件的脚本动效被关闭。

`redesign-frontend-with-shadcn` 已将首页布局同步进主规格。本设计只调整看板主金额、速率位置与展示控制，不改动该布局的导航、设置、购买入口或收藏。

## Goals / Non-Goals

**Goals:**

- 用同一个精确计算结果驱动静态金额与滚动金额，使动效只是视觉过渡。
- 在工作时段连续增长时呈现清晰进位；在大跳变、暂停、减少动态和不支持动效时立即显示正确结果。
- 让暂停后的旧金额明显区别于当前估算，并在恢复时跳至当前时刻。

**Non-Goals:**

- 不改收入公式、刷新口径、金额精度、本月金额动效或保存格式。
- 不增加声音、金币、额外小数位、后台计数、行为上报或个性化动效配置。

## Decisions

### 1. 在主金额展示节点使用数字专用组件

用 `@number-flow/react` 处理位级滚动、进位和千位分隔，沿用现有 `IncomeApp` 的每秒计算结果；不用整页 Motion 动画库，也不改共享 `currencyDisplay`，以免收藏和其他金额一起滚动。主金额仍保留等宽数字、两位小数和完整静态文本的降级路径。每秒速率移到主金额附近，继续复用现有 `rateDisplay` 的小额与阈值语义。本月金额仅更新文字。

选择它是因为完整滚轮要正确处理 `9.99 → 10.00`、`999.99 → 1,000.00`、标点重排和中途取消；在该单点使用专用组件比维护自制多位滚轮更短、更容易验证。只有简单整串淡入的 CSS 方案无法达到方案 B 的按位效果。动效时长先以约 800 ms 的无回弹过渡验证，小于一秒刷新间隔；它不是产品口径或行业定值。

`@number-flow/react` 接收 JavaScript 数值，而领域层支持高于安全整数分位的金额。展示层先从领域输出的两位小数字符串得到精确分位，并仅在分位与转换后的数值往返一致时启用组件；越界、格式不匹配或浏览器能力不足时直接使用 `currencyDisplay` 输出的完整字符串。精确计算与收藏仍使用原始字符串/有理数，不用浮点数按帧加钱。

### 2. 只为相邻的真实增长开启动画

展示层比较上一次与本次已计算的今日金额及其日期、资料版本和时间。只有相邻工作时段更新且金额到分后确实递增时，才把新的显示值交给滚动过渡。首次显示、恢复前台、跨日、保存资料、时钟回拨、从不足恢复，以及手动暂停后的恢复，都直接显示新值并取消旧动画。币符和小数点不滚动；低速时目标分值相同则保持静止。

这是展示资格判断，不修改 `calculateIncome`，也不使用动画进度推导金额。所有可见数字都来自最新的领域结果。浏览器恢复、时区/月切换保持既有的“按当前时刻重算”路径。

### 3. 暂停是当前页面的展示状态

在看板内保存暂停时已呈现的日期、今日/本月金额、速率、工作状态以及暂停时刻；显示明确的“展示已暂停”说明和恢复按钮。计时逻辑可以继续计算当前值，但暂停期间只渲染这份快照；恢复时取当前时刻重新计算，一次替换整份展示快照，不补播。离开看板或重新载入页面后按当前时刻进入实时展示；无需新持久化字段。

如果保存/恢复基础资料使依据改变，或当前计算转为 `insufficient-data`，立即废弃暂停快照并展示新结果或不足原因。这避免旧有效金额被误认为新资料的估算。工作时段的“暂停展示”与午休/休息日的“暂停增长”用不同文案表达。作为替代，单纯停止计时并永久保留旧 React 结果虽然更少状态，却会在资料失效或跨日后留下误导性金额，因此不采用。

### 4. 让完整金额保持可读

减少动态偏好开启或变化时，关闭组件过渡并直接呈现新金额。展示暂停控制独立于该偏好；减少动态只影响运动，不替用户停止更新。辅助技术读取一个完整金额，内部重复数位不进入可访问名称；`aria-live` 不逐秒播报，暂停/恢复的状态按用户操作给出简短反馈。控件保持键盘可达，数位与速率在窄屏不裁切。

## Risks / Trade-offs

- **转换精度** → 对组件输入做分位往返验证；高金额与不支持能力时用原有完整文本降级，绝不为了动效丢分。
- **交错更新与过渡残留** → 在日期、资料、页面可见性或暂停状态变化时取消过渡并直接就位；核验进位和千位分隔。
- **常态动效造成干扰** → 只动变化位，不动本月金额；提供暂停与系统减少动态路径，通过短时反馈检查是否更容易理解而非只看停留时间。
- **暂停旧值被误读** → 明示暂停状态和时刻，依据变化或计算不足时废弃快照，恢复后跳至当前估算。
- **新增依赖成本** → 仅引入单一组件，并用 Bun 锁定版本；若不能在安全精度和无障碍检查中通过，则改用静态金额保底，不以扩大动效框架解决单点需求。

## Migration Plan

无数据迁移。接入后使用合成资料验证桌面、窄屏、减少动态、暂停/恢复及工作/休息边界；若体验不符合预期，移除主金额组件并恢复原文本节点与速率原位置，领域计算、本地资料和快照无需回滚。
