# Proposal

## Why

当前 Jev 辅助填写只处理三个字段，用户仍需确认填入、补表单并再次确认结果。将已确认的一句话输入、必要追问和一次整体确认串起来，减少单次购买任务的重复输入，同时保留用户核对与手动完成的能力。

## What Changes

- 默认展示对话输入，手动填写作为随时可切换的次级入口；共用当前会话草稿。
- 扩展收入、税口径、价格识别至作息、直接月工时及按需余量字段；只根据用户提供的依据整理，不推断固定支出完整性或购买决定。
- 代码根据缺失项展示有界追问与快捷选项，允许跳过；可编辑摘要整体确认一次后查看结果。
- 支持明确改口、字段级估算保护及异步过期响应丢弃；修改后失效旧结果和导出，旧决定不得自动关联新输入。
- 向 Jev 发送当前回答、当前问题与最少相关上下文，首次主动发送前披露；失败保留进度并转手动。
- 同步实施阶段的产品范围与隐私文案，细化主动发送及最少上下文边界；主规格中已过时的无条件“不上传”描述已按用户要求单独修正。

## Capabilities

### New Capabilities

无；本变更扩展既有购买工作台。

### Modified Capabilities

- `purchase-decision-workbench`：对话优先输入、有界追问、摘要确认、改口与决定失效、按需余量、最少上下文及失败接续。

## Impact

- 前端：`src/app/App.tsx`、`src/app/AssistInput.tsx`、相关样式和 `tests/assist.test.tsx`、`tests/app.smoke.test.tsx`；复用 `src/domain/calculation.ts` 的校验与计算。
- 本机 API：扩展 `scripts/jev_server.py` 的 `/api/assist` 请求与响应，复用 `scripts/jev_experiment.py` 候选判断；同步前后端及离线测试，不承诺旧内部请求格式兼容。
- 文档：实施时更新策略、路线图、架构、PRD、页面文案、README 与 ADR-0006/0007 的替代关系；本次仅生成规划产物，不将草案写成已交付事实。
- 不新增依赖、生成式模型、公开部署、账户、持久化或同步；继续 CNY 月度计算与既有 JSON 导出格式，对话原文不导出。
